# Rules
REUSE-1: Action buttons use the shared button(label) export from kit/button.js; local reimplementations are not adopted.
COLOR-1: Action button background is --action and text is --on-action; per-screen color overrides are not adopted.
LAYOUT-1: .stack is approved for ordinary wrapping row composition with --gap. Screen composition does not require its own catalog entry.
Support-text typography is undecided, outside this adopted scope.
