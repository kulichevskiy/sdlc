# Deliver to merge readiness

An explicit `full-stop` request selects unattended delivery to an open, unmerged PR ready for the user to merge. Mentioning or discussing the skill alone does not activate it.

Read and follow the [shared workflow contract](../setup/references/workflow.md) and [unattended delivery procedure](../setup/references/delivery.md). Resume from the user's current agreed intent, spec, tickets, implementation, or PR. Keep this mode active across the remaining stages; the user is away and cannot answer questions.
